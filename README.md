# GreenDen 🌿

GreenDen is a responsive plant and gardening website built using **HTML** and **Tailwind CSS**.

## About the Project

GreenDen is a simple and modern website designed to showcase plants and provide a clean, user-friendly browsing experience.

This project was created to practice **HTML structure, Tailwind CSS styling, responsive design, layouts, and navigation**.

## Technologies Used

- HTML5
- Tailwind CSS

## Features

- Responsive design
- Clean and modern UI
- Navigation bar
- Plant product sections
- Responsive layouts
- Tailwind CSS utility classes
- Mobile-friendly design
